# sql_projects
Database projects 
Programs written in MySQL

1. PolyClinic.sql

This project creates the database for a polyclinic and has tables: Patient, Doctor, Pathology and Pharmacy. The project demonstrates the DDL commands, DML commands, grouping operations, joining operations and view commands.

2. Transactions.sql

This project creates a database that stores transaction details like customer, mode of payment, amount, etc. in table known as Paytable. It demonstrates functioning of stored procedures, stored functions and triggers.
